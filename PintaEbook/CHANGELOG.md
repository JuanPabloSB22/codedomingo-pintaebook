## [0.0.1] — 2026-08-25

Primera versión de la interfaz frontend de PintaEbook.

### Added

* Estructura base del frontend con Angular.
* Sistema de navegación principal.
* Página Home.
* Vistas de autenticación:

  * Inicio de sesión.
  * Registro.
  * Recuperación de contraseña.
* Página de error 404.
* Componentes iniciales reutilizables de interfaz.
* Identidad visual de PintaEbook.
* Tipografía principal: Cormorant Garamond.
* Paleta de colores definida para el proyecto.

### Changed

* Implementación de los diseños aprobados en los wireframes de baja fidelidad.
* Ajustes de estructura y composición para mantener coherencia entre las distintas vistas.

### Fixed

* Correcciones visuales realizadas durante la implementación inicial.
* Ajustes de espaciado, proporciones y alineación de componentes.
